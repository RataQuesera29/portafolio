# Portafolio de proyectos

Sitio personal hecho con GitHub Pages (gratis). Para configurarlo y actualizarlo,
lee **[INSTRUCCIONES.md](INSTRUCCIONES.md)**.

- Proyectos: carpeta `_proyectos/`
- Fotos: carpeta `assets/img/proyectos/`
- Nombre, lema y enlaces: archivo `_config.yml`
- Plantilla para un proyecto nuevo: `PLANTILLA-PROYECTO.md`
